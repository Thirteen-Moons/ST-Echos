# 🌙 ST-Echos 记忆插件 · 使用说明

让 AI"记得"你们聊过什么：把聊天分段总结成小摘要注入对话（近期记忆），攒够摘要后再二次压缩成长期记忆存进世界书（远期记忆）。<br>
> 其实就是大小总结，适合不喜欢用太复杂记忆插件的人群。

<br>
版本：v1.0.0 | 作者：Thirteen-Moons

---

## ⭐ 功能特色

- **高自定义与可控性**：所有设置项与提示词均可按需调整/开关，手动自动自由把控。<br><br>
- **采样参数设置**：总结一般适合低温，插件的采样参数仅在要求总结时生效，其他时候依旧使用你原本设置的酒馆采样参数，不影响聊天。<br><br>
- **与酒馆一致的提示词管理器**：高自由度好上手。<br><br>
- **可自由引用的宏**：不拘泥于固定存放位置，可将记忆在需要的地方自由引用。<br><br>
- **正则**：SillyTavern本身的正则只对聊天渠道生效，因此引入单独的正则，以在发送给总结API前，处理伪思维链、状态栏等内容。<br><br>
- **预览与重说**：不满意总结的内容？可多次重新生成、编辑，满意再存。<br><br>
- **标签筛选**：摘要过多看得眼花，想分类查看？标签解决这个问题。<br><br>
- **隐藏区分**：扩展的 `自动隐藏/临时显示` 功能仅影响被扩展自身隐藏的消息，不会影响到你自己手动隐藏的某条消息。<br><br>

## ⚡快速上手

1. **总结 API（第二层）**：默认用酒馆主聊天 LLM 做总结；勾选"启用自定义API"可换任意 OpenAI 兼容接口（适合本地模型）。填 URL 和密钥后点"连接"测连通并拉取模型列表。<br><br>
2. **自定义提示词**：首条"系统提示词"以真正的 system 身份发送；根据自身需要写清总结要求。Chat History 占位条目=所有未隐藏的消息，自动参与。<br><br>
3. **手动总结**：填"起~止"楼层（0 起，与酒馆显示一致）→ 点"小总结"→ 预览可编辑，保留20次重说历史 → 满意后💾保存进池，新内容在小总结池中被拼接在旧内容下方。<br><br>
4. **自动小总结**：每聊够 N 条自动总结并弹窗提醒去预览，其余功能与手动总结一致。<br><br>
5. **注入对话**：开启注入模板并选位置，模板里写 `{{echo}}` 引用当前聊天的小总结池；也可选择不注入，在酒馆提示词管理器/世界书/任意位置直接引用 `{{echo}}` 宏。<br><br>
6. **大总结**：小总结池攒够后点"进行大总结"（或设自动阈值），预览满意后保存——内容追加进选定世界书条目、小总结池自动清空、已隐藏的楼层依旧保持隐藏。<br><br>
7. **标签**：建标签+关键词后，用"标签筛选"下拉筛选查看对应摘要（多选=同时满足）。
<br><br>

## ❗重要语义（必读）

- **统计与隐藏 vs 小总结池是两套东西**：保存预览 → 记总结到哪了、（开自动隐藏时）隐藏楼层、进池。之后在池里**随意删改摘要不会影响统计和已隐藏楼层**（池只是注入内容）。<br><br>
- **没有"撤销已总结"**：统计只增不减（但删除聊天楼层，统计会自动修正）。某些楼层已隐藏了，但后续又想让 AI 重新看到？用"临时显示已隐藏的楼层"指定区间临时放开。<br><br>
- **临时显示隐藏楼层**：可"所有"或指定 x~x 区间，不碰统计；取消勾选按原样恢复。<br><br>
- **大总结条目**：由插件在世界书里创建（常驻注入、角色定义之前），也可自行创建条目并绑定，可创建多条目，总结内容会保存到选定的条目。创建后你可以在世界书界面自由改它（关闭、改关键词注入、改位置），插件只追加内容、不动你的设置。<br><br>
- **世界书选择顺序**：聊天绑定的聊天世界书 → 角色主世界书 →（都没有时保存会提示）。<br><br>
- **采样参数（主LLM通道）**：off 的参数不覆盖、用主聊天参数；想知道实际覆盖了什么，按 F12 在控制台搜 `主LLM采样覆盖已应用`。

## 📦 安装

将本仓库克隆或下载到 SillyTavern 的扩展目录：

```
 https://github.com/Thirteen-Moons/ST-Echos.git
```

然后在酒馆"扩展"页启用 **ST-Echos 记忆**，刷新页面，点右侧扩展抽屉里的 "ST-Echos 记忆" 展开面板。
<br><br>

### 自定义 API 的 CORS（跨域）说明

浏览器直连本地/第三方 API，部分后端需要放行酒馆的来源（`http://127.0.0.1:8000`）：

- **llama.cpp / LM Studio**：默认放行，一般不用管。
- **Ollama**：启动时加环境变量 `OLLAMA_ORIGINS="http://127.0.0.1:8000"`。
- 连接失败时插件会把"CORS 嫌疑"写进错误提示。
<br><br>

## × 禁用 / 卸载

- 禁用扩展不会立即清掉已注入的内容（注入是内存态），**刷新页面后**即清除。
- 如果你在酒馆提示词管理器等地方写了 `{{echo}}`，禁用插件后宏不会解析、会原样显示，请自行改回。
<br><br>

## 已知边界

- 统计/隐藏没有"永久撤销某段已总结状态"的按钮（可用临时显示或重新总结补救）。
- 大总结条目会持续变长、若开启常驻，每次对话都占上下文，面板上有字数显示，留意即可。
- 更换预设不会动总结池内容和标签（两者都按角色聊天文件各自保存）。
- **小总结池编辑归位规则**：与某条摘要同列表符（`- ` 等）的追加行会并入该条；换格式的文字记为"未关联楼层"段落。不要靠搬动文本给条目排序（会被识别为删除+新增）。
  > 但这对注入内容无影响，仅影响你不知道总结内容对应的是哪个楼层区间。
- 写入数据后约 0.4 秒内切聊天，极个别情况下刚建的内容可能没来得及落盘（酒馆平台写文件耗时）；重要操作后稍等半秒再切换即可。
- 装了 cocktail 且开启"抽屉动画优化"时，自动展开面板的动作有 500ms 兜底强制显示，一般无感。
